# Rugby Scorekeeper

A Flutter app for manually recording rugby matches from the sideline.

## Features
- Create matches and enter home/away teams
- Match clock
- Tries, conversions, penalties and drop goals
- Player/scorer entry
- Yellow/red cards
- Automatic score calculation
- Match timeline and undo
- Full-time summary with try scorers
- Local saved matches

## Run
1. Install Flutter and Android Studio (Android) or Xcode (iPhone).
2. Open this folder in your IDE.
3. Run `flutter pub get`.
4. Run `flutter run`.

This version uses local storage only; no live score API is required.
